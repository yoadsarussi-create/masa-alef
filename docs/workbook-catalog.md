## לבנות קודם (השפעה × כמות עמודים)
1. **בחירה מרובה "סמני את כל…"** — מכסה כיוונים, רק/גם/חוץ מ, הקיפו את המספר, קטגוריות (#3, #4, #8, #10).
2. **השלמה לכמות / כמות שווה** בהקשה (#12, #14, #9).
3. **צבע-לפי-מספר** עם מפתח-צבעים מוקרא (#28, #19, #17) — אהוב במיוחד, וגם מלמד צבעים באנגלית.
4. **מילה יוצאת דופן** (#26) — מבוסס על המילים הקיימות.
5. **מבוך** (#11, #25) — לחזקת מוטוריקה וסדר א"ב.
6. **רכבת-מספרים בגרירה** (#16) + **> < =** (#24, #33).
7. עקיבה עם **מספור משיכות וחצים** כמו בחוברות (#23, #29, #31).
8. סודרים "השלישי משמאל" + גדלים/אורכים (#7, #2, #1).
